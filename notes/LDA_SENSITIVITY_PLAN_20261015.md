# LDA 설정 민감도 분석 계획 — 2026-10-15

## 질문과 고정 자료

원고의 네 가지 비교가 토픽 수(topic count), 불용어(stopwords), 난수 시드(random seed)에 따라 어떻게 달라지는지 확인한다. 전체 20,107편과 arXiv 한국어 25편·중국어 186편·일본어 17편을 고정한다. 연도는 최초 제출 월이며 2026년은 1~9월이다. 기존 `verification/topics_lda_20261015.json`은 보존한다.

- 입력: `preprocessing/output/corpus_llm_agent_all_2023_2026q3.csv`, 표제어 캐시, 기존 문서 배정과 토픽 단어 표.
- 모델: scikit-learn LDA, batch, max_iter=25, 나머지 기본값은 기존 모델과 같다.
- 설정: K=10/25, 불용어 현행/현행에서 datum·cod를 제외, seed=42/43/44. 총 12회.
- K=10은 보류 집합 혼란도(perplexity)가 가장 낮은 기존 후보이며 K=25는 원고 모델이다. 중간 K=15는 이번 한정 검증에 포함하지 않는다.
- 생성기 주석은 datum·cod를 data·code의 표제어 대응으로 설명한다. 이번 비교가 과거 일본어 p값 변화의 원인을 재현한다고 단정하지 않는다.
- 현행 K25 seed42의 문서 배정과 상위 단어를 기존 저장값과 먼저 대조한다.

## 비교와 결과별 서술

| 주장 | 계산 | 유지될 때 | 바뀔 때 |
|---|---|---|---|
| 한국어 training·fine의 비중이 높다 | 대응 토픽의 한국어 편수/25, 전체 편수/20107, 비율의 비 및 한국어 내 순위 | 시험한 설정에서 상대적 집중이 유지된 범위를 보고 | 특정 설정의 배정 결과로 서술 |
| software·execution의 비중이 증가한다 | 연도별 해당 토픽 편수/해당 연도의 전체 집합, 2026과 2023 차이 | 관측 기간 사이 비중 차이를 보고 | 설정별 방향 차이를 보고하고 일반적 추세 주장을 줄임 |
| 한국어 software/retrieval이 0편이다 | 대응 토픽 배정 편수와 25편 각각의 재배정 | 시험한 설정의 관측 수 범위를 보고 | 0편을 고정된 사실로 쓰지 않음 |
| 중국어 retrieval13편이 비교 근거다 | 기존13편의 대응 토픽 유지 편수, 초록 내용 확인, 새 중국어 배정 편수 | 문서와 토픽 배정의 일치 범위를 보고 | 토픽 분할·병합과 내용 차이를 보고 |

기존 토픽 T6(training), T20(software), T22(retrieval)의 상위10단어 Jaccard 유사도와 문서집합 Jaccard 유사도를 모두 구한다. 각각 최댓값인 대응 토픽을 별도로 기록하고, 서로 다른 대상을 고르면 대응의 모호함을 표시한다. 단어가 일부 겹치는 것을 동일한 토픽으로 확정하지 않는다. 문서집합 대응은 기존 토픽 문서가 어디로 이동했는지 보는 기준이다. K가 다르면 토픽 병합·분할이 가능하므로 편수만 비교하지 않는다. p값을 선택 기준으로 쓰지 않으며 새 유의성 검정은 이번 범위에 포함하지 않는다.

## 재현과 한계

설정별 배정 배열·상위 단어를 저장하고 별도 정본 JSON으로 요약한다. 노트북은 저장된 배정에서 분모와 비교 수치를 재계산하여 보존한 JSON과 대조한다. 모델 재학습 명령은 스크립트에 둔다. 초록 내용 확인은 보조 검토이며 사람 판정으로 표시하지 않는다. 제한된 설정 실험은 모든 전처리 선택을 검증하지 않으며 한국어 집합의 작은 규모를 해소하지 않는다.

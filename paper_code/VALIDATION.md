# 검증 범위

2026-10-15, Python 3.13.5에서 확인하였다.

| 항목 | 결과 |
|---|---|
| 입력 설치 | Release 압축 파일의 파일 목록·크기·SHA-256 확인 |
| 분모·표 수치 | 665개 항목 통과 |
| 표 재생성 | 표 1·2·3·4의 LaTeX 출력 일치 |
| 노트북 | 01·05·07·08·10·13번 전체 실행 및 관련 JSON 일치 |
| 테스트 | 12개 통과 |
| LDA 설정 민감도(sensitivity) | 고정 말뭉치에서 12개 설정 학습, 기준 모델 배정 재현 |
| OCR 입력 검토 | 43편의 제목·페이지·요약 범위 대조 후 기존 선정 62편의 키워드군 편수 유지 |

LDA 검증의 조건과 결과는 [검증 안내](../notes/LDA_SENSITIVITY_WALKTHROUGH_20261015.md)에 정리하였다. 13번 노트북은 저장한 12개 모델의 배정에서 결과를 다시 집계한다. 재학습 명령은 [재현 안내](../REPRODUCIBILITY.md)에 있다.

OCR 검토에는 비공개 원문을 사용하였다. 공개 자료로는 저장된 선정·키워드군 판정에서 집계한 값을 재현한다. 이번 검토는 새로운 독립적인 사람 검수나 문자 인식 오류율 측정을 포함하지 않는다.

새 가상환경의 패키지 설치와 설정별 순열 검정은 이번 검증에 포함되지 않았다. 입력·환경·명령과 수치 차이는 실행 시 생성되는 `run.json`에 기록한다.
